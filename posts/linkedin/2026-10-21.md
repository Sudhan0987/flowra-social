# Customer questions already sit in Search Console

3 words in one Search Console filter can hand you next month's topic list: how, what, why.

Those are the questions your pages already show up for. Some of them nobody on your site has answered yet.

This week in r/content_marketing, someone asked how small teams should pick topics when customer questions and search volume disagree. The answer worth keeping: write down the exact question and the decision behind it.

Search Console already holds the exact words. In the Performance report:

1. Add a Query filter, choose Custom (regex) and paste ^(how|what|why)\b

2. Sort by impressions. Each row is someone's own wording, next to the page Google showed them.

3. For each one, write two lines: the question as typed, and the decision the person is trying to make with it.

4. If the ranking page doesn't answer it near the top, that's a rework brief. If no page fits, that's a new page.

When volume and questions disagree, we'd start with the question that has a decision behind it. A small team ships only a few pages a month, so each one should settle something for a reader.

Flowra lists question queries where a page already ranks near the top as featured snippet opportunities, so those are a good place to start.
